常见问题

和 IP 页有什么区别？

IP 页回答「这个地址在哪、是谁的网络」。WHOIS 页回答「这个域名登记在哪、什么时候到期、名字服务器是谁」。同一个域名可以两边都查：这里看注册信息，IP 页看解析和地理。

为什么联系人经常是空的？

2018 年之后，很多注册局按 GDPR 在 RDAP / WHOIS 里脱敏。本站把 redacted: true 显示成「未公开」。滥用投诉要看注册商公开的 abuse 邮箱；没有这项时，注册局就没有给。

查询失败时先看什么？

本地和 Pages 都要有 WHOIS_API_BASE，指向已经跑起来的 who-dat。/health 应返回 {"status":"ok"}。域名本身要能解析成可注册的名字，not-a-domain 会被拒绝。

联系谁？

全站只有 联系 这一页。who-dat 自带的联系表单不是 WhoIP 的入口，部署 API 时不必对访客开放。
