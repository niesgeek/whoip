WhoIP · 唯一联系入口

IP 和 WHOIS
都从这里找人。

顶栏和底栏的「联系」是全站同一个页面。这里没有第二套表单，也不把 who-dat 自带的联系页再挂出来。

hello@example.com 相关链接

上面的邮箱是占位。部署时设置 CONTACT_EMAIL，可选再设 CONTACT_URL。页面会读 /api/site 换成你的地址；函数没起来时，就保持这个占位。

写什么

  • 站点本身：页面打不开、边缘 IP 读不到、WHOIS 一直超时。
  • 不要发注册人隐私申诉：那是注册局和注册商的事。WHOIS 页如果给出了 abuse 邮箱，直接写给那边。
  • 查询记录：本站没有数据库。IP 页的最近查询只在你自己的浏览器里。

怎么换成你的联系方式

在 Cloudflare Pages 的环境变量，或本地 .dev.vars 里写：

env
# 必改。不设就显示 hello@example.com
CONTACT_EMAIL=you@example.com
# 可选，只接受 http 或 https
CONTACT_URL=https://example.com/about
CONTACT_URL_LABEL=关于我们

这三个变量只影响这一页。WHOIS_API_BASE 是另一件事，用来把 WHOIS 查询转到 who-dat，说明写在仓库 README。
